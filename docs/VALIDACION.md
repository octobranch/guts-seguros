# Validación de entrega

## Comprobaciones completadas

- 12 páginas: home y cinco servicios, en ES y EN.
- Un H1 y una canonical propia por página.
- Palabra principal presente en título, descripción y H1.
- Metadatos únicos y alternativas hreflang recíprocas.
- Dos tablas y guías/listas/pasos en cada página comercial.
- Preguntas y respuestas del schema iguales a las visibles.
- Referencias internas del grafo JSON-LD resueltas.
- Recursos y fragmentos locales existentes.
- Sin dependencias de CDN ni bibliotecas de interfaz.
- Formularios por correo, preselección del servicio, copia de mensaje y menú probados mediante un DOM simulado en las 12 páginas.
- Selector ES/EN formado por enlaces HTML reales; no depende de JavaScript.
- URLs y mensajes de WhatsApp en ambos idiomas, incluida la información del servicio.
- Configuración de URL probada en dominio raíz, subcarpeta de proyecto y modo noindex.
- YAML del workflow, permisos y dependencia entre build/deploy comprobados.

## Alcance y límites

Estas pruebas verifican estructura y lógica, no sustituyen una revisión visual en navegador ni una prueba de despliegue en la cuenta de GitHub del propietario. No se publicaron cambios externos, no se midieron Core Web Vitals de un dominio real y no se verificaron posiciones ni indexación en Google.

No se confirmó que el teléfono publicado esté habilitado en WhatsApp. La aceptación, las tarifas y las condiciones de las aseguradoras no se verifican mediante esta web.
